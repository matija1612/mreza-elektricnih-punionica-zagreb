# Mreža električnih punionica u Gradu Zagrebu

Projekt iz kolegija Napredne baze podataka.

U projektu je izrađena grafovska baza podataka električnih punionica u Gradu Zagrebu korištenjem Neo4j AuraDB i Cypher jezika.

## Sadržaj projekta

- `seminar.pdf` – seminarski rad
- `projekt_punionice_jednostavno.cypher` – Cypher kod za kreiranje baze i upite

## Korištene tehnologije

- Neo4j AuraDB
- Cypher
- Portal otvorenih podataka Grada Zagreba

## Funkcionalnosti

- prikaz mreže punionica
- pronalaženje najbližih punionica
- pronalaženje DC punionica
- analiza povezanosti mreže
- pronalaženje najkraćeg povezanog puta između punionica
